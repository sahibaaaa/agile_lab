# HealthTracker App

A team project managed using Jira and GitHub.

## Project Management
- Jira project: [HealthTracker App](https://sahibaafreen.atlassian.net/jira/software/projects/HEA/boards/133)
- Jira board: Scrum sprints for discovery, core development, integration/testing, release preparation, and hardening.

## Working Agreement
- Work on a separate branch for each change.
- Reference the related Jira issue in the branch name, commit message, and pull request.
- Keep pull requests focused and reviewable.
- Test changes before requesting review.
- Do not commit credentials, secrets, or real personal health information.

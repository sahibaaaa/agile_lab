# Definition of Done

A Jira story is considered done when all applicable checks below are complete.

- [ ] All Jira acceptance criteria are satisfied.
- [ ] Changes are committed on a focused feature branch.
- [ ] The pull request references the relevant Jira issue (for example, `HEA-16`).
- [ ] The implementation has been reviewed and approved.
- [ ] Automated tests pass.
- [ ] Relevant integration and regression tests pass.
- [ ] No unresolved critical or high-severity defects remain.
- [ ] Health-data privacy, consent, and security considerations have been checked.
- [ ] QA outcome and any remaining limitations are recorded in Jira.
- [ ] The approved pull request is merged into the target branch.
- [ ] Jira status and notes reflect the actual implementation and review state.

Do not include real personal health data, credentials, API keys, or other secrets in source code, commits, issues, or pull requests.
